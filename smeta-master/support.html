Сохранить и перенести работу

  1. Дождитесь подтверждения, что текущие изменения сохранены.
  2. Откройте раздел резервного копирования и сохраните полную копию через системный диалог Android. Выберите место, доступное отдельно от данных приложения.
  3. Проверьте, что сохранённый файл доступен. На другом устройстве выберите этот файл в разделе восстановления и проверьте показанный состав.
  4. Подтвердите восстановление. Если на устройстве уже есть работа, сначала сохраните и проверьте её страховочную копию: импорт заменяет текущий набор, а не объединяет его с новым.

Полная копия содержит данные и уже созданные PDF. Отдельный PDF удобен для отправки документа, но не заменяет полную копию для продолжения работы. Архив также не является независимой резервной копией. Для работы без интернета выбирайте локальную папку устройства в системном диалоге, например «Загрузки». Доступность облачного поставщика файлов, отправки по почте и сетевого принтера без сети не гарантируется.

Если сохранить не удалось

Не удаляйте приложение и не очищайте его данные. Пока приложение открыто, в нём может оставаться ещё не сохранённый ввод. Используйте штатный повтор и дождитесь успешного сохранения. После закрытия процесса доступно последнее успешно сохранённое состояние.

При сообщении о повреждении не заменяйте файлы случайными документами. Сохраните предлагаемые приложением исходные файлы и восстанавливайте работу из проверенной полной копии. Если ошибка повторяется, напишите в поддержку и укажите точное сообщение.

Объекты, архивы и документы

В бесплатной версии можно редактировать один выбранный активный объект. Число архивных объектов тарифом не ограничено; архивы сохраняют историю и доступны для просмотра, PDF и экспорта. PDF и ручные полные резервные копии с восстановлением бесплатны. Если после переноса несколько объектов числятся в работе, явно выберите один для редактирования: остальные данные остаются на устройстве.

Для просмотра, сохранения и отправки готового документа откройте его PDF. Последующая правка расценок не должна менять уже выпущенный документ.

Важно перед удалением или сменой устройства

Работа хранится локально. В этой версии нет автоматической облачной синхронизации, подключения к Яндекс Диску или серверу разработчика. Автоматическое резервирование Android отключено. Перед удалением приложения, очисткой его данных или сменой устройства сохраните независимую полную копию.

Резервные копии и PDF не защищены паролем. Выбирайте безопасное место и получателей. В приложении нет встроенных рекламы и платёжных сервисов; записи оплат не переводят деньги.

Как управлять статистикой и диагностикой

На главном экране есть переключатель «Помогать улучшать приложение». Он выключен по умолчанию. Включайте его только если хотите разрешить AppMetrica собирать техническую статистику и сведения о сбоях. Для смет, PDF и резервных копий это не требуется.

Чтобы прекратить дальнейшую отправку, выключите переключатель. Если появится сообщение об ошибке сохранения настройки, повторите действие и проверьте её состояние. Уже отправленные сведения отключение не удаляет. Состав данных описан на странице конфиденциальности.

Support

Save and transfer your work

  1. Wait until the app confirms that your current changes are saved.
  2. Open the backup section and save a full backup through Android’s system file dialog. Choose a location separate from the app’s own data.
  3. Check that the saved file is accessible. On the other device, select it in the restore section and review the listed contents.
  4. Confirm restoration. If that device already contains work, save and verify a safety copy first: importing replaces the current dataset rather than merging it.

A full backup contains your data and PDFs that have already been created. An individual PDF is useful for sharing a document, but it cannot replace a full backup for continuing work. An archive is not an independent backup either. For offline use, choose a local device folder in the system dialog, such as Downloads. A cloud file provider, email delivery or network printer may require a connection.

If saving fails

Do not uninstall the app or clear its data. While the app is open, it may still contain input that has not been saved. Use retry and wait for a successful save. After the process closes, only the last successfully saved state is available.

If the app reports damaged data, do not replace files with unrelated documents. Save the original files offered by the app and restore from a verified full backup. If the error persists, contact support with the exact message.

Projects, archives and documents

The free version lets you edit one selected active project. The plan does not limit the number of archived projects; their history remains available for viewing, PDF and export. PDFs and manual full backup and restoration are free. If a transferred backup contains multiple projects marked as in progress, explicitly select one to edit; the other data stays on the device.

Open a completed document’s PDF to view, save or share it. Later rate changes must not change a document that has already been issued.

Before uninstalling or changing devices

Work is stored locally. This version has no automatic cloud synchronisation or connection to Yandex Disk or the developer’s server. Android automatic backup is disabled. Save an independent full backup before uninstalling the app, clearing its data or changing devices.

Backups and PDFs are not password protected. Choose safe storage locations and recipients. The app contains no integrated advertising or payment services; payment entries do not transfer money.

Manage statistics and diagnostics

The main screen has a “Help improve the app” switch. It is off by default. Enable it only if you want AppMetrica to collect technical usage and failure information. This is not required for estimates, PDFs or backups.

Turn the switch off to stop further sending. If the app reports that the preference could not be saved, repeat the action and check its state. Turning it off does not delete information already sent. See the privacy page for the data involved.

What to send to support

  • The app and Android versions.
  • The screen and steps leading to the problem.
  • What you expected and what happened.
  • The exact error text or a screenshot with personal information removed.

Email jonkryl@gmail.com. Do not attach full backups, customer documents, payment details or passwords. If possible, describe the issue using a sample project. Information in your email is used only to answer your question and help with the app.
